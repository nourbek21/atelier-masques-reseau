# Étape 1 — Créer un compte GitHub

⏱️ 10 minutes · Si tu as **déjà** un compte GitHub, passe directement à l'[étape 2](2-utiliser-le-template.md).

## C'est quoi GitHub ?

**GitHub** est un site web qui permet de **stocker du code** et de le partager. Les informaticiens du monde entier l'utilisent.

Un **dépôt** (en anglais *repository*, souvent abrégé *repo*) est un dossier de projet stocké sur GitHub.

## Créer le compte

1. Va sur **https://github.com/signup**
2. Entre ton **adresse e-mail** (de préférence ton adresse **étudiante**, voir l'encadré plus bas).
3. Choisis un **mot de passe** solide (au moins 15 caractères, ou 8 avec un chiffre et une minuscule).
4. Choisis un **nom d'utilisateur** (*username*).
   > 💡 Il sera visible publiquement et tu le garderas peut-être pour ta carrière : préfère quelque chose de sobre, comme `prenom-nom` ou `pnom`.
5. Résous la petite **énigme de vérification** (pour prouver que tu n'es pas un robot).
6. Clique sur **Create account**.
7. Ouvre ta boîte mail : GitHub t'envoie un **code à 8 chiffres**. Recopie-le sur le site.
   > ⚠️ Pas de mail ? Regarde dans les **spams / courriers indésirables**.
8. Connecte-toi avec ton nom d'utilisateur et ton mot de passe.
9. Si GitHub te pose des questions (rôle, intérêts…), tu peux cliquer sur **Skip** / **Continue for free**. Le compte **gratuit** suffit.

## 🔐 Double authentification (2FA)

GitHub peut te demander d'activer la **double authentification** : en plus du mot de passe, tu devras saisir un code temporaire affiché par une application sur ton téléphone (*GitHub Mobile*, *Google Authenticator*, *Microsoft Authenticator*…).

- Suis les instructions à l'écran.
- **Télécharge et garde précieusement les codes de récupération** (*recovery codes*) : sans eux, si tu perds ton téléphone, tu perds ton compte.

## 🎓 Bonus : le pack étudiant (facultatif)

Avec une adresse e-mail étudiante, tu peux demander gratuitement le **GitHub Student Developer Pack** sur https://education.github.com/pack : il donne accès à GitHub Pro et à de nombreux outils. Ce n'est **pas nécessaire** pour cet atelier (la validation peut prendre plusieurs jours).

## ✅ C'est bon si…

Tu es connecté(e) sur https://github.com et tu vois ton avatar en haut à droite.
